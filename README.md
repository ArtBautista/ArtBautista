### 🧪 About Me

I'm a **Software Development Engineer in Test (SDET)** specializing in end-to-end and API test automation. I build reliable, maintainable test frameworks that catch bugs before users do — with a particular focus on **UI automation (Selenium)**, **API testing (RestAssured)**, and **security-aware QA** (auth, IDOR, input validation).

- 🔍 I care about test *quality*, not just test *coverage* — flaky tests are technical debt.
- 🏗️ I design frameworks around the **Page Object Model**, clean locators, and reusable API clients.
- 🛡️ I treat security testing as part of functional testing, not an afterthought — especially on fintech/data-sensitive apps.
- 📊 I believe good reporting (Allure, Extent) is as important as the tests themselves.
